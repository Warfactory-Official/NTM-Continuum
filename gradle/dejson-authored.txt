# Dejson declares uniform boilerplate only: sprite items, cube_all-style parent+texture blocks, simple
# blockstates, loot, tags, recipes. A file whose content is hand-tuned — custom `elements` geometry, `display`
# transforms, one-off raw OBJ item definitions — is written and edited as JSON (Blockbench can open it), never
# transliterated into Element.box(...).face(...) chains or JsonObject calls.
#
# One path per line, relative to src/main/resources; a line ending in `/` exempts a whole folder.
# Read by ../Golem-Core/gradle/mod/dejson.gradle.kts through golem.build.dejson.authored (dejsonOwnership: a
# listed file may be authored in a Dejson-owned folder, and a listed path that does not exist fails the build)
# and by port-tools/generator_safety.py (generators may not write these files either). Taking a file back from
# a declaration: add it here AND delete the declaration — an authored file silently wins over a declaration at
# the same path.
